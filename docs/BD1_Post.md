C программаар FCFS, SJF, Priority, Round Robin, Priority + Round Robin алгоритмуудыг ажиллуулж болно. Вэб симулятор Gantt диаграммаар үр дүнг алхамчилж харуулна. C программын гаралтыг симуляторт импортлоод CPU-ийн дараалал, процесс тус бүрийн хугацааг тулгаж болно.

Шүүмжийн дагуу оролтын хязгаар, процесс солилтын тоо, TID бүртгэл, вэбийн импортын шалгалтыг шинэчилсэн. C-ийн 18 үндсэн шалгалт, вэбийн 16 бүлэг болон C код, вэб симулятор, импортын 133 харьцуулалт давсан.

Эх кодыг задалсны дараа төслийн үндсэн хавтаснаас `make test` ажиллуулна. Вэб симуляторыг `src/web/index.html` файлыг хөтөч дээр нээж ажиллуулна.
