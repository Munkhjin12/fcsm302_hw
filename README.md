# IV-2-8 - CPU хуваарилалтын алгоритмууд

**F.CSM302 Үйлдлийн систем, Бие даалт 1**  
**Гүйцэтгэсэн оюутан** Л.Мөнхжин /B242270094/  
**Шалгасан багш** Г.Ганбат

Энэ төсөл Operating System Concepts номын 10-р хэвлэлийн 5-р бүлгийн Scheduling Algorithms даалгаварт үндэслэсэн. C хэрэгжилт нь FCFS, SJF, Priority, Round Robin, Priority + Round Robin алгоритмуудаар процессуудыг хуваарилж, ажилласан дараалал болон процесс тус бүрийн waiting, turnaround, response хугацааг хэвлэнэ. Вэб симулятор нь эдгээр тооцоог Gantt диаграммаар харуулахын зэрэгцээ SRTF, таслалттай Priority, өөр өөр ирэх цагийг турших боломжтой.

## Ажиллуулах

`IV-2-8.zip` файлыг задалж, `IV-2-8` хавтаснаас дараах командыг ажиллуулна. C хэсэгт C11 дэмждэг GCC эсвэл Clang, `make`, `sh` шаардлагатай.

```sh
make
./src/c/fcfs tests/schedule.txt
./src/c/rr tests/schedule.txt 4
```

Вэбийг ашиглахдаа [src/web/index.html](src/web/index.html) файлыг орчин үеийн хөтөч дээр нээнэ. **Номын жишээ** ачаалагдсан үед алгоритм сонгож **Ажиллуулах** дарна. Дэлгэрэнгүй алхмыг [ажиллуулах гарын авлагаас](docs/USER_GUIDE.md) үзнэ.

## Оролтын хүрээ

`schedule.txt` файлын нэг мөр `name, priority, burst` гэсэн гурван талбартай. Нэр нь захын хоосон зайг арилгасны дараа 1-63 UTF-8 байт урттай, давхцаагүй байна. Нэрэнд таслал, дөрвөлжин хаалт болон ASCII удирдлагын тэмдэгт оруулахгүй. `#`-ээр эхэлсэн тайлбар, хоосон мөрийг алгасана.

*Хүснэгт 1. C болон вэбийн оролтын хүрээ.*

| Үзүүлэлт | C программ | Вэб симулятор |
|---|---|---|
| Процессын тоо | 1-1000 | 1-20 |
| Ирэх цаг | Бүгд 0 мс | 0-10 000 мс |
| CPU хугацаа | 1-1000 мс | 1-1000 мс |
| Эрэмбэ | 1-10, их утга түрүүлнэ | 1-10, их утга түрүүлнэ |
| Ээлжийн хугацаа | 1-1000 мс, анхны утга 10 | 1-1000 мс |

C-ийн нэг физик мөр 255 хүртэлх байт байна. C гаралтын бүх `Running task`, процессын үзүүлэлтийн хүснэгт, гурван `Average` мөр болон `Schedule summary: tasks=<n> end=<time>` төгсгөлийн мөрийг хамтад нь вэб рүү импортлоно.

## Шалгах

Бүх шалгалтад Node.js 22 болон C-ийн хөрвүүлэх хэрэгслүүд шаардлагатай.

```sh
make test
```

Энэ команд C-ийн дундаж үзүүлэлт ба алдааны 18 шалгалт, оролтын хязгаарын шалгалт, гар тооцоотой 7 дараалал, процессын үзүүлэлтийн хүснэгт, олон урсгалт бүртгэл, вэбийн 16 регрессийн бүлэг, C/симулятор/импортын 133 харьцуулалтыг ажиллуулна. Найман урсгалын бүртгэлийн шалгалт нь бодит `new_task()` руу 1008 оролдлого хийж, зөвшөөрөгдсөн 1000 TID болон бүртгэлийн мөрийг шалгана.
